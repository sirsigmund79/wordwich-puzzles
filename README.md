# wordwich-puzzles

## Letter Loaf

Daily three-round puzzles (`puzzles/YYYY-MM-DD-ww2.json`), generated by
`puzzles/generate-puzzles.js`. Each round gives a start letter and an end letter
and asks for words that fit.

### Generate the next 30 days

```bash
cd puzzles
node generate-puzzles.js --days 30
```

`--days N` picks up the day after the last puzzle already in the folder, so it
is safe to re-run — existing dates are skipped, and hand-authored puzzles are
never overwritten. Add `--dry-run` to see the schedule without writing files.

### Other useful flags

```bash
node generate-puzzles.js                                # today only
node generate-puzzles.js --date 2026-07-04              # one specific date
node generate-puzzles.js --start 2026-07-01 --end 2026-12-31
node generate-puzzles.js --start 2026-07-01 --days 14
node generate-puzzles.js --force                        # redo existing AUTO puzzles
```

### How difficulty works

Rounds on the same day are *not* held to the same target, because letter pairs
are not equally rich. Every pair gets a **ceiling** — the score of its 20 most
familiar matching words, ranked using `puzzles/word_frequency.txt`:

| Pair | Ceiling | Why |
|------|---------|-----|
| K-A  |  33 | KARMA, KAPPA, KOALA, and then you're stuck |
| K-S  |  70 | KIDS, KNOWS, KISS, KEEPS, KEYS… |
| E-A  | 129 | EXTRA, EUREKA, ENIGMA, ENCYCLOPEDIA… |

A round's `perfectScore` is that ceiling times the day's **reach** factor, so a
hard day asks you to find more of what a pair actually offers rather than
pasting one number onto three unequal pairs. What each day guarantees is a
**peak**: at least one round must reach the day's anchor score, and none may
exceed it. So `32 / 57 / 90` in a single day is the intended shape, not a bug —
the 32 is a genuinely barren pair. Tune all of this in `DAY_PROFILE` at the top
of the script.

Two data files feed the generator, both committed:

- `puzzles/word_frequency.txt` — the game's own words ordered most-common-first;
  line number is the familiarity rank. Drives ceilings.
- `puzzles/hint_words.txt` — curated everyday words, used to keep `hintWord`
  recognizable. Frequency alone is not enough: subtitle data ranks HONG and
  PERRY above CHARM.

## Griddle

Every Griddle puzzle lives in `griddle/puzzles.json`, keyed by date. The game
reads that file (through the site's `/api/puzzles` function, which hides days
later than tomorrow), so **pushing to `main` is publishing**: there is no
Google Sheet any more, and no site build or deploy.

`griddle/generate-griddles.js` builds 5x5 word-intersection grids (Easy, Medium,
Hard), validates the words against the Free Dictionary API, and appends the new
days to `puzzles.json` with the next griddle numbers and puzzle ids.

### Generate the next 30 days

```bash
cd griddle
node generate-griddles.js --days 30
```

`--days N` starts the day after the last day already in `puzzles.json`, so it is
safe to re-run. Review the diff, commit, push.

### Easy really is easy

Each difficulty only draws words at or above a Zipf frequency floor
(`minZipf` in `GRID_CONFIG`), using `griddle/word_zipf.txt` — the same
wordfreq numbers Letter Loaf uses to call a word rare:

| Difficulty | Every word at least | Roughly |
|---|---|---|
| Easy   | Zipf 3.5 | everyday words (TOTAL, DELAY, PLATE) |
| Medium | Zipf 2.5 | known but less common |
| Hard   | no floor | anything the dictionary accepts |

Previously one obscure word (often a fallback forced by the crossing letters)
could end up in any round: 84% of Easy grids had a word under Zipf 3. Difficulty
also still comes from how many cells start filled in.

`word_zipf.txt` is the 5-letter rows of `public/wordbank.txt` in
wordwich-game. Re-copy it if that file is rebuilt.

### Other useful flags

```bash
node generate-griddles.js --date 2026-12-04             # a single date
node generate-griddles.js --start 2026-12-01 --end 2026-12-31
node generate-griddles.js --days 7 --dry-run            # print only, puzzles.json untouched
node generate-griddles.js --date 2026-12-04 --replace   # regenerate a day that isn't live yet (keeps its ids)
node generate-griddles.js --skip-validation             # skip dictionary API checks (no definitions)
node generate-griddles.js --no-dedupe                   # skip recent-word exclusion
```

Words used within 40 days of a date, or by another difficulty on the same
date, are excluded. So is anything in `griddle/blocked_words.txt` (crude or
grim words); add to it freely.

### Editing a puzzle by hand

Edit the day in `puzzles.json` and push. Each puzzle has `solutionGrid`,
`staticCells` (`true` = starts filled in, `null` = hole), `words`,
`definitions`, and optionally `par` and `extraLetters`. Never change an `id`
once its day is live: players' saved progress is keyed on it.

### History
